Fasol.fun Verify

Every round is provably fair. Before the round starts, a commit hash is published. After the crash, the server seed is revealed. Use this tool to verify that the crash multiplier was predetermined and not manipulated.

Verify a Round

The commit hash is SHA-256 of the seed alone, so it does not change with the game number. The game number goes into the crash multiplier: leave it empty to check only the commit.

Crash Multiplier (seed + Game #)
Commit Hash (SHA256(seed), same for any Game #)

How It Works

Before each round, the server generates a random seed and publishes its SHA-256 hash (the commit hash). Players place bets only seeing the hash. After the crash, the seed is revealed — anyone can verify it matches the hash and recompute the crash multiplier.

// 1. Commit (before round)
commit_hash = SHA256(server_seed)

// 2. Crash multiplier (deterministic)
input = server_seed + "crash" + game_seq_le64
hash = SHA256(input)
v = hash[0..8] as uint64 LE
raw = floor(10000 × 264 / (v + 1))
mult = clamp(raw, 10000, 1000000) / 10000

// Result: 1.00x to 100.00x
